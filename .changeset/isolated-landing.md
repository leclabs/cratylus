`plan land` refuses, writing nothing, a commit its unit was not built apart for, while the unit's plan is bound: a commit the repository cannot resolve, a commit the main checkout's HEAD already contains (a unit built in the operator's checkout, on its branch or on one switched to there), and a commit the plan's line already contains (a unit built in the line's own worktree). A commit made in another worktree on a branch off the line is recorded as before. The refusal says in the plan's words which holds for which unit and commit, and that nothing was written; it names no git command, branch or worktree path. `plan assay`, `plan whole` and `plan broke` are unchanged, and a land on a unit of a plan that is not bound refuses as before.
