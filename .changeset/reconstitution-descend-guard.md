Canon ships the `descend` guard (`descend`), bound to `tool.use.pre`, whose judge answers `{"descends": boolean, "reason": string}`. The architect's fixed `conceptual-elevation` stance is held by it (`guarded(conceptualElevation, descend)`), so a tool call that opens, searches, edits, builds, tests or runs the work itself, instead of the design, the examples, the journal, the ledger or a delegate, is refused with the tell `descending`. The architect's session-start note now asks for the readback in visible text before any act, in the agent's own communication style, and then for the operator's request to be carried on in the same turn.
