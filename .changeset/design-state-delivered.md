The delivered agents reconstitute from the design state (decision 0294). The `reconstitution` procedure reads the design state of each context it touches and of the delivered workflow first, then the standing decisions its work needs, then the work in flight from the project's version control and the lead's outcomes, and reads back the current design, then what is open (competing versions and open decisions), then the stories and tasks in flight. The `concept-journal` perception scope is the recorded design per bounded context, with decisions of realization read apart. The architect records each ruling of meaning, one applying the design included, as a concept version with its reason before reporting it, never as a decision, and renders its read-backs in plain words from the design state.

The omp session-start note names the design state of each touched context and of the delivered workflow, then the standing decisions, never an overview or cuts; its read-back is rendered in plain words from the design state. The per-turn meaning note says a ruling of meaning is recorded as a concept version with its reason, never as a decision.

The `frontier-other-family` model value keeps its fallback (decision 0244): the strongest of another model family than the builders' where one is available, any available model otherwise. The omp `--agent` flag starts the session as the agent definition omp discovers by that name.

The delivered agents, their assignment and deliverable forms and the omp harness notes name the restated concepts by their established names (decision 0296): user story, code review, handoff, hold point, delegation of authority, conceptual model, work product, agent harness, agent definition, persona drift and version history. Four values take the new sign as their own: the assignment `story` is now `user-story`, the deliverable `review` is now `code-review`, the perception scope `work` is now `work-product` and the stance `proportionate` is now `tailoring`; the forms' field keys are unchanged. The `signify` skill calls what a concept's anchor leaves unsaid, the right side of its cell, its differentia.
