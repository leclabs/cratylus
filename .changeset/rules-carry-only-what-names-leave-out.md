Every installed rule is stated by its Cratylic name, with a precising definition only for what the name leaves out and a why only where the name does not carry it. A rule's `why` is optional and its omp file carries a `Why:` line only when it has one. The conventional-commits ruleset becomes the one rule `conventional-commits-adopted` and established-libraries the one rule `established-libraries`; an installation that chose the earlier rules is asked about the new names.
