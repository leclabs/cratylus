On omp, an agent cratylus installed, launched with `omp --agent` or dispatched, has a system prompt that opens with its definition, followed by omp's own prompt as the installed omp builds it each turn, without the passages cratylus judged contrary to the persona or bloat; every other passage is kept, a newer omp's included. A judged passage the installed omp no longer holds is named in a warning at session start.
