On omp, a guard's verdict is the last JSON object in the judge's answer that carries its verdict field, so prose or a fence around it no longer leaves the act unjudged; an answer with no such object still refuses nothing and is reported. A guard whose judge reads the conversation ends what it is given with a one-line reminder of the answer's form.

A session launched as an agent, and every dispatched one, is refused an `eval` call whose code dispatches a delegate (`agent(…)`, `workpool(…)`, `tool.task`, `tool["task"]`), with `dispatch: dispatch a delegate with the task tool, where its assignment is checked.`: such a dispatch reaches no `task` call, where its assignment is checked, the dispatch guards judge it and the readback gate holds it.
