The concept journal is the only home of cratylus's conceptual model, and INTRODUCTION.md is its entry point. CANON.md, VISION.md, MODEL.md, ENGINE.md and ARCHITECTURE.md are deleted, and no README or source comment points at them any longer. The repository's `AGENTS.md`, projected from canon's `repo-preamble` rule, now sends a session to INTRODUCTION.md and the concept journal and carries the current working conventions. The ground-conformance gate, which read MODEL.md, is removed, and the cratylism gate no longer looks for those document names.
