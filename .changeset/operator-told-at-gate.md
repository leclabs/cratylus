Attach on omp tells the operator: as soon as a delegate holding a gate waits on the operator's sign-off, by whatever route its turn ended there (its dispatched run, a later run the operator or a dispatcher's or peer's message started, a background delivery), the operator's own session shows a warning line naming the agent and how to join it in omp's Agent Hub (Alt+A, select the agent, Enter), however deep the holder sits below other delegates. The notice is omp's `notify`, which no model reads, given once per gate.
