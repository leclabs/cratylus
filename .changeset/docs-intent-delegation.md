The documents describe intent-based delegation. The repository's working conventions (`AGENTS.md`, the `repo-preamble` rule) follow GitHub flow with a `dev` branch: a short-lived branch per task merged into `dev` by pull request, `dev` merged into `main` by pull request for a release, and an integration branch ahead of `dev` for one change only when a session says so; pushing needs the operator's say-so. The runtime's README names its three capabilities, `concepts`, `ledger` and `versionSkew`, and tells the ledger's stories, tasks and recorded runs; forge's README tells the omp extension's handover forms, warned when incomplete and never refused, and its recording of runs; the `cratylus` README's practice example is `intent-based-delegation`.
