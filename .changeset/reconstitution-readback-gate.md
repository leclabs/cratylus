On omp, a session launched as an agent whose procedure starts with reconstitution changes nothing before its readback. Until the session's judge finds the current design, open decisions and cuts in flight in what the agent has told the operator in visible text, each dispatch, file write or edit, and appending verb of a capability is refused with `reconstitution: give the operator the readback …`. A call that only reads is never held; with no verdict the act goes through and the session is told it was not judged. The session-start note now names the journal, the ledger and the example files as the only sources, asks for the readback first with its bottom line, and limits the turn to what the operator asked.
