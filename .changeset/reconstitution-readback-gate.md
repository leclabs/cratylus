On omp, a session launched as an agent whose procedure starts with reconstitution changes nothing before its readback. Until the session's judge finds the current design, open decisions and cuts in flight in what the agent has told the operator in visible text, each dispatch, file write or edit, and appending verb of a capability is refused with `reconstitution: give the operator the readback …`. A call that only reads is never held; with no verdict the act goes through and the session is told it was not judged. The session-start note now names the journal, the ledger and the example files as the only sources, asks for the readback first with its bottom line, then for the operator's request in the same turn, settling on sight what the agent holds.

Both the session-start note and the hold apply only where the launch starts a session with no conversation since its last compaction, and again when the session is compacted (`session_compact`); a session resumed to continue a conversation is neither told to reconstitute nor held.
