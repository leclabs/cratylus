The practices the agents work by reach every agent as skills rendered from cratylus's own domain model. Two new skills, `cratylic-context-design` and `behaviour-driven-development`, each hold their bounded context's name and subject and every concept of it as `<term> ≜ <correction>`, byte for byte as `design/model/<context>/` records it; canon's build reads the records into `generated/practices.json`, which the package ships and never commits, so no concept is restated by hand. Every profile whose procedure names a practice loads its skill: a composed agent carries them as `skills`, in procedure order, which omp receives as `autoloadSkills` — the business analyst and its personas both, the tech lead, software engineer, test engineer and code reviewer behaviour-driven development. The `cratylic-context-design` procedure value is now its bare term; its skill carries the practice. `cratylus install` places both skills.
