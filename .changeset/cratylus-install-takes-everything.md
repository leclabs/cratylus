`cratylus install` offers no practices choice: it installs every agent and skill of the canon, and the rulesets stay offered as before. Run with no terminal and naming only the harness, it installs everything and is never refused for want of a choice. An earlier installation's recorded practices are not read.

BREAKING CHANGE: `cratylus install` no longer takes `--practices` or `--all`; a script passing either must drop it.
