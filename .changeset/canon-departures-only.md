Each canon value, role description and skill description now states only cratylus's departure from its name, and nothing as a prohibition. Twenty-three values are invoked by their name alone — the action scopes `none`, `run-checks`, `commit-own-paths` and `edit-own-outputs`; the autonomy `principal`; the communication style `provenance-attribution`; the expertise `research-investigation`, `software-delivery` and `specification-by-example`; the guardrail `accountability`; the models `fast`, `frontier`, `low`, `medium`, `high`, `xhigh` and `max`; the objectives `correctness` and `review-accuracy`; the perception scopes `outside-research` and `work-product`; and the stances `dry` and `user-centered` — and the stance `llm-native` keeps only "writes for a model reader: clear, direct, explaining why". The guardrail values `never-repairs` and `no-implementation` are removed (breaking: a profile importing either no longer compiles); the code reviewer no longer holds `never-repairs`, its deliverable, a code review naming each finding, carrying what it hands back. The software engineer's description is "Realizes one task and hands back one change."; the `signify` skill's description asks for "an established term wherever one covers it", and the `materialize` skill's description no longer says "never restating them".
