`cratylus --explain` given with any other word (`cratylus --explain install`, `cratylus --version --explain`) is refused as a usage error, one stderr line and exit 1, running nothing. The `cratylus` package describes itself with the command's purpose, and the READMEs say that `cratylus` with no arguments prints how to start, without restating the orientation.
