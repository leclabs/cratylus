Where the operator has asked to review a change before it joins, the operator's review is that change's review (decision 0292): it is Ask with the operator as its one reviewer, held-out examples included, and no agent reviews the change as well. The lead's role states that it has no agent review such a change and holds the operator's review as its gate, and its `ship-show-ask` note that no agent reviews that change, which joins only once the operator signs it off. The reviewer's role and description end that it never reviews a change the operator has asked to review itself. Held-out examples are withheld from builders and taken directly by whoever reviews, a reviewer or the operator, never through the lead. The lead's story contract's `review` field says the same of the operator's review.
