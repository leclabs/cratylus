'@cratylus/canon': minor

Each agent invokes its industry role by name and states only cratylus's departures from it, each by its Cratylic name with a precising definition only where the name leaves a symmetric difference. No agent holds behaviour-driven development as a procedure any more: the project adopts the practice by its conventions. What the industry's role already carries by its name is no longer restated (among others a tech lead's software delivery, a code reviewer's code review, a test engineer's test-first, each engineering role's drive, expertise and engineering stances, the guardrails its decision rights already imply). The departures kept follow the domain model: decision rights as one RAPID letter per decision class, every agent's autonomy as mission command, reach open by default, the domain model as living documentation in `design/model/` held in memory, a user story free-form and unestimated, sign-off by default on each user story and its examples before its build and on each release, Ship/Show/Ask's Ask as the product owner's review before a change joins, tailoring per user story by its risk, and architecture decision records as one standing file per decision, which the tech lead now keeps. The business analyst's deliverable is a backbrief, in the industry's terms, until the product owner concurs, replacing its report, and its register is plain rather than layman. nico is restated in Cratylic names, giving each concept its Cratylic name with a precising definition only for the symmetric difference that remains; its cold-reader stance is retired.
