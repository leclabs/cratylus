## Intent

Enumerate the minimal cell/archetype set every founded mind-society instantiates — the "foundational
structure all societies are built on" — as one structure cell.

## Outcome

- **`ideas/politeia.md`** authored (kind: structure). **Naming call**: anchored `politeia` (Aristotle's term
  for the constitution *of* a polis) over the plan's descriptive working name `foundational-structure` — it is
  the densest-faithful point and harmonizes with the civic-Greek family (polis / oikos / koine / apoikiai).
  *Flagged for Lex's signify review; trivial rename if rejected.*
- The politeia indexes the minimal constitution in five strata, each citing its members (cite-dont-copy):
  **personhood** (ambient-person-agent, identity-memory-stack, continuity-thread, the memory cycle),
  **identity** (agent-identity-portability, named-marker-as-index-key), **authority** (scope-grant,
  subject-binding, sovereign, principal-agency, genuine-fork, scope-precedence-merge-algebra), **cultural
  propagation** (substance-over-accident, archetype-instantiation, commons-distribution, adopt-the-commons),
  **the founding** (founder-charter, operator-relation, consensual-adoption). Minimal archetype set = the two
  founders (nico, mav).
- Distinguishes the *constitutional kernel* (what every society **is**) from the rest of the corpus (craft a
  society **may** practice) — keeping the set minimal. Back-linked from founder-charter (the seed).
