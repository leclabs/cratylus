# The names in this directory were RETRO-FITTED — they are not the names in use at the time

`61b85db7` (2026-08-05, `refactor(names)!`) swept every retired brand out of the whole tree — content
**and paths** — and this directory was in scope. **13 files here were rewritten.**

These are **closed records**. A record edited to match today is no longer a record. What the sweep
took was not the text — git holds every original byte — but the reader's knowledge that a
substitution happened. This note is that knowledge, put back.

**This directory's own address was retro-fitted too.** It was `plans/.retired/agent-runtime/` until
`61b85db7` moved it here. Nine of the files below are that move. Any citation of the old path — and
there were several — now resolves to nothing, and the plan that _argued about_ a name today sits at a
path named for the answer.

To read what a file here actually said, **you must ask for its OLD path** — nothing under
`plans/.retired/runtime/` exists at `61b85db7^`, because the directory itself did not exist yet:

```sh
git show 61b85db7^:plans/.retired/agent-runtime/PLAN.md
```

Names below may therefore be **anachronistic**: a decision recorded under one name reads as though it
had been taken under the name that replaced it. Where a file's SUBJECT _is_ a name — a brand
derivation, a bin migration, a signification that returned `⊥` — read it against `61b85db7^` before
citing it, or the finding inverts.
