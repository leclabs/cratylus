# t-signify-the-pulse

**Wave 0.** Derive the anchor, or return `⊥` with the evidence that says so.

## The concept, stated so this shard leans on no other document

An **endogenous pulse on a cadence that SAMPLES a pressure/salience gate to decide whether a
cognitive cycle runs — it never CLOCKS one.** `consolidate` is `false` on every tick while
pressure sits below threshold, no matter how many ticks elapse. The pulse is intrinsic (it
fires with no external trigger); the decision is not the pulse.

## Method

`/signify` — cold decode against the model's priors, never coined. The corpus's instrument is
`packages/canon/tooling/cold-oracle/`, which calls the live model with zero project context.

1. Forward: candidate signifiers for the concept.
2. **Reverse (the decisive leg):** hand each candidate to a reader with NO access to this
   repository and record what concept it circumscribes. The anchor is the one whose blind
   reverse decode returns the concept above.
3. Occupancy: reject any candidate already bound in this repository.

## Constraints

- **`heartbeat` is disqualified before the search starts**, and the reason is recorded in the
  port: this runtime already binds it as a session-LEASE verb. Its accidental mass here is
  exactly the sense that must not attach.
- **`⊥` IS A LEGAL ANSWER.** If no candidate's reverse decode returns the concept, the
  provisional path stands. A coinage is not the fallback — the absence of an anchor is a
  finding, not a failure to produce one.
- Record the residue. An anchor whose residue is ∅ _is_ σ\*; every other is an approximation
  with its shortfall stated rather than explained away.

## Accept

1. Either an anchor with its blind reverse decode recorded, or `⊥` with the candidates tried
   and what each returned.
2. No candidate advanced without an occupancy check against this repository.
3. Nothing renamed yet — this shard produces the derivation, not the move.
