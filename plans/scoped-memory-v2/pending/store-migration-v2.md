one review pass); (4) remove `SELF.md`/`MEMORY.md` after verified move; (5) `audit --home` green
(default-allow file for reviewed pins); (6) wake smoke: the agent's next wake on that host loads
SEMANTIC + PROCEDURAL whole and reports continuity intact (bias-next-action check).

  `.bak` archives present; audit exit 0; spot-read (judge): no disposition text in SEMANTIC, no bare
  identity facts in PROCEDURAL (the split is real, not a rename).
- One deliberately mis-split seed (a law left in SEMANTIC) is caught by the judge pass — prove the
  review bites, then fix.
- A post-migration wake transcript on ≥2 hosts (one per founder) shows the same continuity-thread
  resumed (names its prior thread correctly, no orientation loss).
