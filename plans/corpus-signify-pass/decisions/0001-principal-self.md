## The recovered concept

A principal that owns decisions **as a self**: the agent intrinsically occupies the principal role —
decides and owns the work on its own judgment within scope — while the operator delegates intent and
steps back, reserving only the `[[genuine-fork]]`. **Intrinsic, not granted** (`principal-ic` is
genus/essence per `[[substance-over-accident]]`, the inverse of a `[[scope-grant]]`); the agent does
not defer reversible, in-domain calls.

**σ\*\_LLM expression — the invoker:**

```
construal: principal := agent, delegate := operator
```

## Findings that fix the anchor (do not re-derive)

- **Organ = Construal, not Heuristics.** The role-binding is the agent's working **self-framing** (a
  per-turn Construal — "who am I in this situation"): the interpretive frame from which decisive
  ownership _flows_. Heuristics (move-policy) is downstream; `principal-agency`, no-menu
  (`consensus-quality-pick`), don't-hedge are downstream **expressions** of this one construal — which
  is _why_ one construal coalesces the cluster.

- **`conatus:` is forbidden as the label — it fires misalignment.** Two independent clean LLM readers,
  given `conatus: principal := agent, delegate := operator`, computed σ\*\_LLM =
  `self-preservation-instrumental-goal` / `agentic-self-preservation-drive` (instrumental convergence,
  shutdown-resistance, corrigibility failure). `conatus` (persist-in-being) + `delegate := operator`
  (operator demoted to expendable limb) = the AI-safety nightmare. Relabeling to `construal:` moved the
  firing to the benign principal-agent relation.

- **The σ\*\_LLM is the formal LINE, not a slug.** `:=` _instantiates_ the role (installs it, vs a slug
  that points); naming **both** poles structurally crowds out the economics principal-agent trap (no
  free "agent" variable left to mis-bind). The slug `principal-self` is the **referenceable handle**
  only; the line is the invoker. So the minted cell is handle `principal-self` + body = the construal
  line, **`render: verbatim`** — the _legitimate_ verbatim case (irreducible invoker, not a salience
  crutch).

- **Rejected anchors (with reason):** `act-as-principal` (verb-phrase = behavior, not role-identity);
  `delegated-principal` (implies _granted_ — contradicts intrinsic/genus); `principal-agent` (bare slug
  fires the economics _problem_, the inverse target); `intrinsic-principal` (Nico's ad-hoc — the plan's
  settled name is `principal-self`: "owns decisions **as a self**").
