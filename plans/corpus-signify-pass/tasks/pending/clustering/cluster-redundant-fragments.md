# cluster-redundant-fragments

**Objective.** Turn the harvest into concrete **merge-candidate clusters** — sets of fragments
communicating the same idea — each with a hypothesis for the single concept beneath them. Surface
the `principal-self` cluster (principal-ic / principal-agency / sovereign) explicitly.

**Preconditions.** `harvest/harvest-reference-set` produced the reference set + similarity flags.

**Operations.** Group the flagged anchors into candidate clusters; for each, draft the suspected
single intended concept + which fragments would coalesce; rank by corpus impact. Nico vets the
groupings (his anchor-routing judgment).

**Artifacts.** `plans/corpus-signify-pass/research/merge-candidates.md`.

**Acceptance (blind test).** Each cluster lists its member anchors + a one-line "they all try to say
X" hypothesis; `principal-self` is among them; the list is ready to feed `/elicit`.
