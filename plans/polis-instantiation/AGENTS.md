# polis-instantiation (Phase C)

**Goal.** The operations that stand up a real mind-society in a project — the payoff of the telos:
Operators base new projects on polis, or rebase existing ones, and the founders provide the structure.

**Scope.** The `init` (greenfield) and `rebase` (brownfield) operations built on the constitution
(Phase A) and the machinery (Phase B); Oikos as the first real proving ground; the fleet-deploy migration.

**Lead.** Nico (the founding/restructuring semantics) + Mav (the operational machinery, the fleet seam).

**Two modes, not one problem.**
- **Greenfield** — instantiate culture into an empty project; agents born as founders. Clean.
- **Brownfield** — an agent born into an existing society reads and restructures it to align. Harder, but
  **consensual** (the Operator opted in): the founder is an *invited reformer*, not a conqueror (cf. A4).

**Exit criteria.**
- `init` founds a new mind-society in an empty repo; `rebase` aligns an existing one.
- Oikos is rebased onto polis (its forked dispositions reconciled to projections).
- Fleet deployment migrated from playground to polis, reconciled against deployed state.

**Depends on:** polis-constitution (A), polis-machinery (B).
