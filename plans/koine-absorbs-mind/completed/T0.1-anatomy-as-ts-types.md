# T0.1 — The anatomy as a TypeScript type system (the contract)

**Phase** 0 (foundation) · **Lane** Nico (anatomy authority) + Mav (TS) · **Depends on** none · **Gates** all of Phase 1 & 2.

## Reframe

The "agent anatomy schema" is **TS types**, not JSON Schema. mind source is TypeScript; composition is ESM; a wrong organ→value is a _compile error_. This task defines the type system both mind (source) and koine (projection) bind to. It lives in **koine** (mind imports it).

## Scope

1. **Organ types** — one type per organ value-shape: `Persona`, `Mandate`, `Charter`, `Instructions`, `Effectors`, … (24 organs). Each fragment is `{ definiens: string, ...organ-specific }`. Encode genus (STANCE/CONATUS), open/enum, and **arity in the type**: scalar organs take one value; the 5 set organs (charter, competence, effectors, heuristics, instructions) take arrays.
2. **`Fragment`** — the base type a value-cell module exports (`{ organ, slug, definiens, mark? }`). Identity = the module (path + export), so the `(organ,value)` pair-keying is structural — `effectors/emitFencedReview` and `enaction/emitFencedReview` are different modules.
3. **`Agent`** — a typed organ-selection object: `{ name, persona: Persona, mandate: Mandate, charter: Charter[], ..., base?: Agent }`. Scalar fields one value; set fields arrays.
4. **`Skill`** — `{ name, trigger, delineation, verb, formalBlock, composition: Ref[] }` where composition is plain ESM imports (no `[[ ]]`).
5. **Derivation as typed functions** — persona→description, provenance→{emoji,hue}→color; genus/founder/memory injection as composition helpers.

## Acceptance criteria

- A koine module (`@leclabs/koine` types export) defining all 24 organ types + `Agent`/`Skill`/`Fragment`, such that a fragment with the wrong organ, or a scalar set on a set organ (or vice-versa), is a **compile error**.
- The types are sufficient to express the current corpus losslessly (validated in T1.x by migrating real cells against them).
- No JSON-Schema reference machinery, no `Ref` resolution pass — composition is ESM `import`; "every ref resolves to one home" is `tsc`.
- Documented: these types are THE anatomy contract; the prose docs (`docs/agent-conceptual-anatomy.md`) become the human projection of them.

## Out of scope

Migrating cells to modules (T1.x); projection (T2.x).

## Delivered — the contract location

**The anatomy contract is `packages/koine/src/anatomy/index.ts`**, exported from
`@leclabs/koine/anatomy` (a sibling subpath to the config-IR `Agent`/`Skill` in `@leclabs/koine`,
which are the _translation_ shapes — distinct concept, distinct home, no name clash). These TS types
ARE the anatomy; `docs/agent-conceptual-anatomy.md` is their human projection.

Type surface (`@leclabs/koine/anatomy`):

- **Axes** — `Genus` (`STANCE`|`CONATUS`), `Classification` (`enum`|`open`|`coined`), `Arity`
  (`scalar`|`set`), `Organ` (the 24-name union), `SetOrgan` (the 5 set organs), `Mark` (`{emoji,hue}`).
- **`Fragment<O,G,C,A>`** — `{ organ, slug, definiens, mark? }` + phantom `__genus`/`__classification`/
  `__arity`. The `organ` literal is the structural discriminant: `effectors/x` ≠ `enaction/x`.
- **24 per-organ types** — `Address Persona Mandate Comportment RegisterFit Disclosure Provenance`
  (STANCE) · `Telos Charter Instructions Heuristics Competence DispositionMemory Gestalt Effectors
Sensors Substrate Ledger Percept Construal Deliberation Resolve Enaction Appraisal` (CONATUS). Each
  pins its (organ, genus, classification, arity) tuple.
- **`Agent`** — `{ name, base?, …24 organ fields }`; scalar organs hold one fragment, the 5 set organs
  hold `readonly T[]`. Arity enforced by the field types ⇒ scalar-given-array / set-given-scalar is a
  compile error. `base?: Agent` is the `...base` spread target (T0.2 baseline/delta).
- **`Skill`** — `{ name, trigger, delineation, verb, formalBlock, composition: Skill[] }` + optional
  deploy directives (`deployAs?: 'skill-dir'`, `bundle?`, `assets?`). `composition` is imported sibling
  `Skill`s — no `[[ ]]`, no Bindings prose; the import IS the binding.
- **Derivation helpers (stubs)** — `personaToDescription`, `markToColor`, `provenanceMark`.

Negative-case proof: `packages/koine/src/anatomy/anatomy.test-d.ts` — `@ts-expect-error` directives
(checked by `tsc --noEmit`, the `typecheck` gate) for wrong-organ→wrong-field, non-`Organ` literal,
scalar-given-array, set-given-scalar (both as bare fields and inside an `Agent` literal), and a
`[[ref]]`-string in `Skill.composition`. Plus positive constructions: a full 24-organ `Agent`, a valid
delta-over-base (`...base` + scalar override + additive-set spread), and a composed `Skill`.

Acceptance met: `pnpm --filter @leclabs/koine build` + `tsc` pass, types exported from the package,
`pnpm test` (126) + `pnpm lint` green. No cells migrated; nothing committed.
