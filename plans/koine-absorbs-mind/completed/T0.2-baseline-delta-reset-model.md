# T0.2 — Baseline/delta + reset model (spec)

**Phase** 0 (foundation) · **Lane** Nico · **Depends on** none (pairs with T0.1) · **Gates** T2.2, T4.1.

## Reframe — two distinct resets, correctly filed

| reset                                     | what                                                                                                    | lives in                 |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------ |
| **harness reset** (`claude`, `codex`, …)  | what _that harness_ provides natively (the blind-`/introspect` measurement) — basis for omit-to-inherit | the **koine adapter**    |
| **agent base** (genus / HHH / continuity) | polis-universal, harness-**neutral** floor every mind agent inherits                                    | **mind** (a base module) |

`claude` is a **harness**, not an agent. The "claude baseline" is the claude adapter's reset, not a mind agent.

## The semantics (all native JS, no bespoke machinery)

- **Composition** = ESM `import`.
- **Merge** = object spread: `nico = { ...base, persona: sage, charter: [...base.charter, inputUntrusted] }`. Scalar override = field replace; additive set = array spread; remove = filter (rare).
- **Inherit-by-omission** = don't set the field (spread fills it from base).
- **Delta-over-target** = computed **in the adapter at export**: the adapter subtracts its own harness reset, so the projected artifact omits what the target already provides. Same agent, minimal-per-harness automatically.
