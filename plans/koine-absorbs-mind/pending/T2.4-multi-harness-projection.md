# T2.4 — Multi-harness projection (the free win)

**Phase** 2 (adapters as projection) · **Lane** Mav · **Depends on** T2.1 · **Gates** nothing.

## Reframe

Because projection IS the export adapter, authoring a mind agent once makes **every koine adapter a projection target** — mind → {claude, codex, cursor, gemini, …} for free. Prove it.

## Scope

1. Project ≥1 mind agent + skill through a **second** adapter (codex: `AGENTS.md` + `agents/<name>.toml`) end-to-end, applying the codex harness reset (T2.2 pattern).
2. Confirm honest lossy reporting where an adapter is `partial`/`none` for agents (cursor/opencode skip+warn, not corrupt) — reuse koine's existing `WriteReport`.

## Acceptance criteria

- A mind agent projects through codex (and the round-trip / capability reporting holds).
- Documented: the set of harnesses mind now reaches for free, with per-adapter agent-support (full/partial/none).

## Out of scope

Per-harness reset accuracy for every adapter (incremental); deploy (T3.1).
