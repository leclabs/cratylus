# T6.1 — Cutover: retire the Python toolkit, mind builds via koine

**Phase** 6 (cutover) · **Lane** Mav (engine) + Nico (verify/corpus) · **Depends on** T2.1, T3.1, T4.1, T1.\* · **Gates** plan retirement.

## Scope

1. **Single pipeline** — `koine` composes (ESM), projects (adapters), and deploys the whole corpus; one command, fleet-aware. The manual `mind.koine.json` fixture handoff is gone.
2. **Migrate verify** — corpus-structural checks become `tsc` + lint + the byte-identical round-trip gate; the claude-specific gates (`gate_roundtrip`, `gate_verbatim_ref_free`) reframe against the claude adapter projection. Keep the self-application acceptance law.
3. **Retire `packages/mind/toolkit/` (Python)** — `resolve.py`/`deploy.py`/`compose/*`/`render/*`/`place/*` removed or reduced to a deprecation shim once koine reaches full parity. Update `packages/mind/toolkit/AGENTS.md`, `packages/mind/AGENTS.md`, root `AGENTS.md`.
4. **Docs** — `docs/agent-conceptual-anatomy.md` + cell-format docs reframed: the anatomy IS the TS types; markdown is a projection; composition is ESM; mind is koine's core plugin.

## Acceptance criteria

- One koine command renders + deploys the corpus to all targets, fleet-aware, **byte-identical** to the legacy mind pipeline (final self-application gate).
- Python toolkit retired/shimmed; CI green (`pnpm build/test/lint`); docs updated; plan retires.

## Out of scope

New harness adapters beyond koine's existing set.
