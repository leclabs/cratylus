# T1.1 — Migrate organ value-cells → typed TS fragment modules

**Phase** 1 (mind as source) · **Lane** Nico (corpus) + Mav (codegen) · **Depends on** T0.1 · **Gates** T1.2, T1.3.

## Scope

Convert every organ value-cell (markdown) into a typed TS module exporting a `Fragment`. Markdown becomes a _projection_, not the source.

1. **Codegen tool** — a one-time migration that reads each `<organ>/<value>.md` and emits `mind/organs/<organ>/<value>.ts` (`export const <camelSlug>: <OrganType> = { definiens: \`…\`, … }`). Prose (definiens, mark) → backticked literals.
2. The `(organ,value)` pair-keying becomes the module path; no global-slug ambiguity.
3. Formal-block-bearing cells keep their math/symbol-table content verbatim in backticked literals (no fence-immunity needed — interpolation is explicit `${}`).

## Acceptance criteria

- Every current value-cell has a typed `.ts` module; `tsc` passes (types from T0.1).
- **Round-trip:** projecting each fragment module back to its markdown form is byte-identical to the current cell body (the self-application gate).
- Wrong organ/arity is a compile error.

## Out of scope

Agent/skill modules (T1.2/T1.3); projection adapters (T2.x).
