**Phase** 3 (deploy) · **Lane** Mav · **Depends on** T2.1 (needs projected artifacts; otherwise independent) · **Gates** T6.1.

## Scope

Absorb every deploy/placer capability that lives only in mind's Python today (koine stops at `compile`). koine gains a deploy layer that takes projected artifacts → host `.claude/` trees:

1. **Placer** — local + ssh/scp, agent-NAME join key (`<name>.md` def ↔ `<name>/SELF.md` sidecar).
2. **Write policy** — `regenerate` (defs overwritten) vs **`seed-if-absent`** SELF/MEMORY/EPISODIC sidecars (never clobber; EPISODIC seeds empty). koine must STOP unconditionally overwriting.
3. **`.polis.config` host topology** — reuse the existing JSON + `docs/polis-config-schema.md`; reimplement loader/precedence/validation + `--fleet`/`--only`/`--exclude` + the no-default-user hard-error.
4. **skill-dir dual-deploy + bundle staging** — render SKILL.md from a verbatim `## Tool` section; stage `bundle:` build artifacts beside it (hard-error if missing); copy `assets:`.
5. **Scope resolution** (user/project, bare-home guard, `--home` default) + **founding** (`init`: project corpus + lay AGENTS.md + plans/ scaffold; no sidecar seed) + **never-prunes** deletion policy.

## Acceptance criteria

- `koine deploy` reproduces mind `deploy.py` on a scratch target: same files, same if-absent seeding (existing sidecars untouched), same fleet resolution (`upmav=lcaraccioli`, `upgoose` excluded).
- A hermetic two-host fixture proof; the bundle hard-error fires when `episodic.mjs` build output is absent.
- `pnpm build/test/lint` green.
