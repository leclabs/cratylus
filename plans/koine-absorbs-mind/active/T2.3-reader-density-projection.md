## Reframe

The reader-density axis (weak-llm / strong-llm / strong-llm-lean) is **just a projection parameter** — different template-literal functions over the same typed fragments. No baked-in profile, no separate IR.

## Scope

1. A `density` parameter (or per-density projection fns) in the projection layer: `strong-llm-lean` (name-only refs), `strong-llm` (name + delineation), `weak-llm` (+ kind/verb cue).
2. The provenance header records the density (as today).

## Acceptance criteria

- The same corpus projects byte-identical to current `strong-llm-lean` output, AND can project at `weak-llm`/`strong-llm` from the same source with no re-authoring.
- Density is a function arg, not a property of the source modules.
