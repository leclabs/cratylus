# T0.1 — The anatomy as a TypeScript type system (the contract)

**Phase** 0 (foundation) · **Lane** Nico (anatomy authority) + Mav (TS) · **Depends on** none · **Gates** all of Phase 1 & 2.

## Reframe

The "agent anatomy schema" is **TS types**, not JSON Schema. mind source is TypeScript; composition is ESM; a wrong organ→value is a _compile error_. This task defines the type system both mind (source) and koine (projection) bind to. It lives in **koine** (mind imports it).

## Scope

1. **Organ types** — one type per organ value-shape: `Persona`, `Mandate`, `Charter`, `Instructions`, `Effectors`, … (24 organs). Each fragment is `{ definiens: string, ...organ-specific }`. Encode genus (STANCE/CONATUS), open/enum, and **arity in the type**: scalar organs take one value; the 5 set organs (charter, competence, effectors, heuristics, instructions) take arrays.
2. **`Fragment`** — the base type a value-cell module exports (`{ organ, slug, definiens, mark? }`). Identity = the module (path + export), so the `(organ,value)` pair-keying is structural — `effectors/emitFencedReview` and `enaction/emitFencedReview` are different modules.
3. **`Agent`** — a typed organ-selection object: `{ name, persona: Persona, mandate: Mandate, charter: Charter[], ..., base?: Agent }`. Scalar fields one value; set fields arrays.
4. **`Skill`** — `{ name, trigger, delineation, verb, formalBlock, composition: Ref[] }` where composition is plain ESM imports (no `[[ ]]`).
5. **Derivation as typed functions** — persona→description, provenance→{emoji,hue}→color; genus/founder/memory injection as composition helpers.

## Acceptance criteria

- A koine module (`@leclabs/koine` types export) defining all 24 organ types + `Agent`/`Skill`/`Fragment`, such that a fragment with the wrong organ, or a scalar set on a set organ (or vice-versa), is a **compile error**.
- The types are sufficient to express the current corpus losslessly (validated in T1.x by migrating real cells against them).
- No JSON-Schema reference machinery, no `Ref` resolution pass — composition is ESM `import`; "every ref resolves to one home" is `tsc`.
- Documented: these types are THE anatomy contract; the prose docs (`docs/agent-conceptual-anatomy.md`) become the human projection of them.

## Out of scope

Migrating cells to modules (T1.x); projection (T2.x).
