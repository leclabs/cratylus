# T2.2 — Per-adapter harness reset + delta-over-target (file `claude` correctly)

**Phase** 2 (adapters as projection) · **Lane** Mav + Nico · **Depends on** T0.2, T2.1 · **Gates** T4.1.

## Scope

Give each koine adapter its **harness reset** and make export subtract it, so a projected artifact omits what the target already provides (inherit-by-omission, per harness).

1. **claude adapter reset** — the Claude Code default profile measured by the blank `/introspect` (filed HERE, under the claude adapter — NOT as a mind agent). Encode the knob organs Claude Code provides (effectors/tools, model/substrate, address=on-the-loop, the CC instruction set).
2. **Delta-over-target at export** — when projecting an Agent through the claude adapter, subtract the claude reset: organs whose effective value equals the harness-provided value are omitted from the artifact; the rest are emitted. (Set organs: emit the set-difference.)
3. Conformance: the claude reset MUST equal a blank `/introspect` on Claude Code (measure↔declare). A drift check fails if they diverge.

## Acceptance criteria

- The claude reset lives in the claude adapter; `claude` appears nowhere as a `mind/agents/*` module.
- Projecting an agent omits harness-provided organs (e.g. `effectors`, `address`) and emits only the agent's distinctive delta.
- `/introspect` on bare Claude Code == the claude adapter reset (conformance test).

## Out of scope

Other adapters' resets (incremental); density (T2.3).
