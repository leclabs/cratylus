# reader-llm-default

**Anchor** `reader-llm-default` — σ\* blind-gated 2026-07-01 (cold expr-only read converged on it exactly);
`llm-native` is the adjacent principle organ. Lead: Nico.

**The initiative.** Make **reader=LLM the enforced default** for every artifact whose functional reader is
an LLM — source cells, projected SOULs / skills / hook-prompts, agent instructions (`AGENTS.md` /
`CLAUDE.md`), plans, agent memory, skill-generated agent-artifacts on consumer projects, and agent↔agent
messages. Reader=human is the **narrow exception** — valid only when a human is the literal reader (human
chat, `README` / human-docs, human-facing code comments, commit messages, human-facing generated outputs).
Kill the recurring degradation to reader=human prose.

**Core principle — the signifier carries the load.** A σ\* an agent already holds fires the concept via
latent priors, so R=LLM = _signify, don't explain_ (σ\* + only the residue the priors miss). A definiens
that re-explains a firing σ\* is an **ME violation**, not merely verbose. Formalized as σ\*\_R with R=LLM
(the `signify` spine); this initiative instantiates R per artifact class and enforces it on **bodies**, not
just names.

**Why a plan, not another pass.** Sequential hand-passes by nico have **not held** (recurring regression).
So: find the ROOT CAUSE → install a GATE (`codify ⇒ lint ⇒ conform`) → FAN OUT remediation to subagents
with **nico as acceptance judge**. Load distributed, degradation made non-recurring — not routed through one
context.

**Bar already proven.** 4 nico definiens densified (curate / parsimony / decision-rationale /
research-investigation; ~25% each; CE∧ME; signifier-first) — the R=LLM bar the fan-out applies.
