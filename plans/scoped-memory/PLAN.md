# scoped-memory

**The initiative.** Make an agent's own memory (`SELF.md` + `MEMORY.md`) **provably free of project- and
plan-specific content**, by homing every memory at the narrowest scope that dominates its uses — and by
routing both episodic _capture_ and dream _consolidation_ through that scope hierarchy. Agent-owned files
hold only cross-project, agent-intrinsic identity; project/plan facts live at project/plan scope.

**Why now.** mav's memory has palimpsested into project pollution: `MEMORY.md` ≈ 27 KB of web-platform /
Upwork / direction-site facts; `SELF.md` carried a project-specific "Open threads" block. The Operator
hand-corrected on upmav (2026-07-01) — gutted `SELF.md` to _"only system-specific guardrails; ¬Project,
¬Ops, ¬Soul"_ and moved "Open threads" into the active plan's `AGENTS.md`
(`web-platform/plans/direction-site-v2/AGENTS.md`). That hand-fix is the spec seed; this initiative
generalizes it into the memory + praxis systems, corpus-wide.
