# Version skew is reported, never resolved by dispatch

The installation records the version of cratylus that projected it. The version skew capability reports that version beside the version of the cratylus command its capabilities reach, with the installation's scope and root. At every harness startup the extension compares the two and, when they differ, warns at once, naming both versions and the remedy: run install again, at the installation's scope, with the cratylus in use. Nothing dispatches to a project's own pinned cratylus, and no shim chooses between builds.
