# A protected path is guarded in the extension

A path an action scope reserves, such as `design/model/` for `write-domain-model`, is protected: the canon declares it on each agent holding that action scope, and cratylus's omp extension refuses, through a `tool_call` handler, a write to it by any other agent's session. omp's agent `tools` grants whole tools, and `tools.restrictedFolders` gates reads and refuses in headless subagents, so neither carries it.

A subagent session is guarded unless its agent writes the path, omp's own agents included; a main session is guarded only when launched as an agent of cratylus that does not write it, so the product owner's own session is not. The file tools that write, edit or delete are judged by the paths they resolve, and no other tool is judged: the tools that read pass, and so do `bash` and `eval`, whether they read or write. Reach is open by default and narrowed where harm is observed, and the observed harm is a file tool's write; judging a shell or eval call by its text refused every read it named and still passed a path built at run time, and judging it by its effect needs a ledger and locks across processes.
