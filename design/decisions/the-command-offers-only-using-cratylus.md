# The command offers only using cratylus

The shipped `cratylus` command offers install, uninstall and the capabilities, which are exactly the model check and version skew. It has no authoring commands and reads no project configuration file: install installs the agents, skills and rules the command is built with, and ignores a `cratylus.config.ts` in its working directory, which a check pins. A plugin other than that corpus is not something cratylus offers. Code only removed paths reached is removed with them.
