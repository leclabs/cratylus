# Agent launch through the cratylus extension

The cratylus omp extension registers `omp --agent <name>`. It resolves the name through omp's own agent discovery, the same declarations dispatch uses; opens the session's system prompt with the declaration, its front matter rendered as prose and its body kept, for a cratylus agent (omp's own prompt follows it, changed as `omp-prompt-is-changed-by-removal.md` states), and appends it after omp's prompt for any other declaration; applies the declaration's model and effort; and shows the agent's name and mark on the status line. An unknown name stops startup with an error. No launcher exists outside the harness.
