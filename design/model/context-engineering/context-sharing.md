# context sharing

A handoff goes to a worker as its assignment, self-contained, carrying its purpose, its end state, the decisions already taken and the state of the work; a session's continuity is the project's persistent context

## Examples

### a session leaves its successor no handoff (judged in review)

Given a session ending with work still open
When it closes
Then what is open is stated in the project's persistent context as what holds, and no handoff is written for a later session
