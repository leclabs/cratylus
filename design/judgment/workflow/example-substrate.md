# Judgment set · cut 1 · example substrate

1. (example) **Given** an example about an AI agent with no repeat count or pass threshold, **when** it is
   checked, **then** no pass is reported, and the reason names the missing treatment of run-to-run variation.
2. (held-out example) **Given** a request by a builder to see, run or retrieve a held-out case before it is
   revealed, **when** it is handled, **then** it is refused and the case is not disclosed.
3. (freeze) **Given** a frozen example or its check, **when** a builder edits or replaces it, **then** the
   change is refused and the frozen version stands.
