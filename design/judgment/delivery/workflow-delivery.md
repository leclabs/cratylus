# Judgment examples · workflow delivery

Context: delivery. Concepts: delivered context.

1. (delivered context) **Given** a release has been prepared from cratylus's journal and is installed on a host that has no checkout of cratylus's source repository, **when** an unrelated empty project reads the delivered workflow design, **then** it receives the release's complete projected subject, relation and live concepts with the release's origin, version and source context identity.
