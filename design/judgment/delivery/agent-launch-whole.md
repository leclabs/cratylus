# Held-out · agent launch, the whole declaration

Used only in judgment.

1. (agent launch) **Given** a declaration that names no dispatch targets but has the dispatch tool, **when** a
   session is started as it, **then** it may dispatch exactly what the same agent may when dispatched.
2. (agent launch) **Given** a session started as an agent with skills loaded at start, **when** it is
   compacted, **then** those skills are still loaded afterwards.
3. (agent launch) **Given** a declaration whose dispatch list is empty, **when** a session is started as it with
   the dispatch tool granted, **then** it can dispatch no one.
