# Held-out · simplification

Used only in judgment.

1. (binding) **Given** an agent dispatched with an assignment whose field has the wrong type, **when**
   the dispatch is made, **then** a warning names the field and its expected type, and the agent starts.
2. (enforcement-level) **Given** an advisory value breached by an agent, **when** the act is made,
   **then** the breach is shown and the act takes effect; it is never refused.
