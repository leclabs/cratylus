# Palimpsest

A **palimpsest** (Greek _palimpsestos_, "scraped again") is a manuscript whose earlier text was scraped off and overwritten, the old writing still ghosting through beneath the new. As an anti-pattern: any artifact — a cell, a doc, a code file — that **accretes the visible layers of its past** instead of presenting only its current state.

The tells: an abandoned name carried forward; a superseded direction narrated ("the old X was stripped and is not reintroduced"); changelog residue in prose ("(resolved)", "previously", "now takes", "amended-by", "née"); a compat note for a path no longer taken. Each is a stratum the reader must read _through_ to reach the present meaning.

A palimpsest is rot specifically because the artifact no longer circumscribes its idea cleanly ([[precise-circumscription]]) — it circumscribes the idea _plus the scar tissue of its edits_, and charges every future reader for an edit history that has no vote.
