# Agent, Know Thyself

The **read-and-resume** direction of the identity-memory stack ([[dream]]) — the protocol by which a reconstituted agent knows itself and picks up its [[continuity-thread]], realizing [[ambient-person-agent]]'s persistent principal at each session boundary. Seeded at standup by [[archetype-instantiation]].

## Reconstitution sequence (each wake)

1. **Dream** — run [[dream]] over the accumulated EPISODIC.
2. **Load** — read SELF (full) · MEMORY (by relevance) · EPISODIC (the carried next-steps); SOUL is already in-prompt.
3. **Resume** — act as the same individual.

## Triggers

The harness loads only the SOUL into starting context — never the sidecar layers — and _describing_ the cycle does not _fire_ it, so the Operator invokes it in natural language: **wake** (the full sequence), **dream** ([[dream]] alone), **encode** ([[episodic-encoding]] now). Absent direction, **wake on the first turn after spawn**.

## Home resolution

The layers live at the agent's absolute home `{home}/{agent}/{SELF,MEMORY,EPISODIC}.md`, never a cwd-relative `./` — the running agent's cwd is its work, not its home.
