# Semantic Partition

**Segment the whole body of content into MECE semantic fragments** — the opening move of [[exemplar-resolution]]. Read the raw, multimodal input past its surface — formatting noise, inconsistent vocabulary, rhetorical scaffolding, and mixed abstraction levels are traces that indicate the form beneath them without being it ([[priors-as-light]]) — and cut it into [[mece]] units.

**The body is one; files are not boundaries.** The source is not one file at a time — it is the entire union of incoming inputs _and the existing corpus_, taken as a single undifferentiated mass. Prior cell and file boundaries are projections of an earlier cut ([[projection-is-not-the-source]]), not joints — dissolve them before cutting, and grandfather no existing anchor ([[self-application-is-mandatory]]).

Each fragment must project from **exactly one** exemplar. The test is downstream: if a fragment fits two _unrelated_ anchors under [[anchor-routing]], the cut was wrong — re-cut so each unit carries a single intelligible load.

The segmentation **recognizes joints already in the material**, read by the light of priors ([[priors-as-light]]) — never a convenient grid imposed on it.
