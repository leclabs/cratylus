# Densest Faithful Point

Every expression has one optimum: the point where **removing any token lowers fit** (it under-reaches its exemplar — lost fidelity) and **adding any token does not raise it** (the surplus dilutes). Sit each unit exactly there.

Corollary: **verbosity is the signal of a _missing_ anchor**, not of added precision — if it takes many words, the dense name hasn't been found yet — the compression peer of [[precise-circumscription]] ([[anchoring-is-self-similar]] holds the pairing).

Corollary: **named anti-density patterns are surplus this optimum dissolves.** Redundant qualifiers ("very"), filler transitions ("in addition to this"), hedging ("should probably"), activity-narration over outcome, and generic value-claims are all tokens whose removal does not lower fidelity — they are the catalogue of "adding a token does not raise fit," not a separate teaching. Any fixed authoring budget (N concepts per unit, M tokens per concept, a principles/examples ratio) is a **scope-bound parameterization** of this optimum, not a second criterion: the universal is "sit at the point," the numbers are a delta a substrate supplies.
