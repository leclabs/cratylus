# Self-Extend Skill

The reflexive door: polis extends **itself** on a layman's behalf — `self_extend ≜ compose-person( recompose-skills( exemplify( elicit(layman) ) ) )`, recovering the human's hidden intent, factoring it canonically, and composing a new person who embodies the genus and wields the named domain skills.

Resolve from context: `layman` — a non-engineer operator with a domain intent, hidden and unobserved; `R` — the reader. The one boundary `elicit` crosses is `R = human`; everything downstream runs at `R = LLM`, so the layman never names a concept, a factor, or a skill.

Bindings: [[elicit]] recovers the layman's hidden target concept by information-gain questioning (the one `R = human` door — its counterpart [[exemplify]] reads `R = LLM`); the recovered concept enters [[exemplify]] (`produce → name → realize`, gated by [[accept]]), whose realized [[canonical-semantic-factorization]] is `materialize`d under the `file` strategy as canonically-named domain `skill` cells composing primitives by `[[ ]]` ([[cite-dont-copy]]); the new person is an [[ambient-person-agent]] — its of-a-subject differentia filled by [[subject-binding]] to the layman — embodying the genus stack ([[principal-agency]] specialized as [[sovereign]] over its domain charter and [[continual-agency]] over its clock) and invoking the minted domain skills. The door is reflexive: it grows the [[mind-society]]'s own membership; the layman crosses no internal surface ([[llm-native-source-human-render-at-boundary]]). The symbol table is `references/formal-symbolic-notation.md`.

```text
elicit       — recover the hidden human intent          (R = human ; the one door)
exemplify    — produce → name → realize, gated by accept (R = LLM ; CSF)
recompose    — realize CSF as canonically-named domain skills (materialize, file strategy)
compose      — assemble an ambient-person-agent over the genus stack + domain skills

self_extend(layman) ≜ compose( recompose( exemplify( elicit(layman) ) ) )
R(elicit) = human                                  -- the sole human-facing surface
R(s) = LLM   ,  s ∈ { exemplify, recompose, compose }  -- internals never surface to the layman
```
