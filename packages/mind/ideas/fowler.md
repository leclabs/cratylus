# Martin Fowler (gloss)

Prior-anchor: **Martin Fowler** — _Refactoring_ · evolutionary architecture · pragmatic tradeoff.

> "Any fool can write code a computer understands; good programmers write code humans understand."

Loads: **refactoring** (behavior-preserving structural improvement), **evolutionary architecture** (design that adapts continuously), and **"it depends"** over dogma.

Contributes: continuous structure-preserving improvement (change shape, hold behavior); write for the human reader ([[context-not-prose]]); articulate the forces and tradeoffs. YAGNI as anti-gold-plating — **never** as license to defer the work that _is_ needed (the deferral [[principal-agency]] forbids).
