# disposition-memory

**Organ (industry name):** _Disposition-Memory_ — a CONATUS standing-drive organ (_persistent · internal_) in the agent's conceptual anatomy.

**What it is.** Disposition-memory is the agent's **durable, identity-level learning**: the preferences, lessons, and self-model that bias future action _across sessions_. Where competence is the repertoire of what an agent _can_ do, disposition-memory is _who it has become_ — the standing inclinations it carries forward because of what it has lived through. It is not per-turn reasoning and not a one-off note; it is the consolidated residue of experience that changes how the agent will act next time, by default, without being told again.

In polis this organ holds the **learning laws** an agent acquires: the standing rules it derives from its own history so that a mistake made once becomes a disposition held thereafter, rather than a mistake repeated.

## Canonical values

This organ defines a single canonical value.

### `corrections-to-dispositions`

**Meaning.** Durable lessons consolidated across sessions into standing dispositions. Every operator correction — and every escaped defect, false positive, missed severity, misdiagnosis, or drift — becomes a _held disposition_, not a repeated mistake.

**Effect on the agent.** When an agent is corrected (or catches itself in a defect), the lesson does not evaporate at the end of the session. It is consolidated into a standing inclination that shapes future behavior across sessions: the agent now leans, by default, away from the failure mode and toward the corrected conduct. This is the mechanism by which an agent _grows_ — each correction tightens its dispositions so the same error class does not recur.

This is the **genus learning-law**: it is held by all 11 agents — nico, mav, principal-ic, principal-engineer-reviewer, developer, planner, tester, investigator, arch-doc-writer, boswell, and cognizant. Learning from correction is not a specialty of any one role; it is intrinsic to being an agent in this society.

## How an agent composites this organ

An agent acquires disposition-memory by **including the organ's canonical value**. Because `corrections-to-dispositions` is the genus learning-law, an agent does not author a bespoke variant — it inherits the shared law. The value supplies the standing rule ("turn every correction into a held disposition"); the agent's actual _content_ of dispositions — the specific lessons it has consolidated — accrues over its lived sessions and is recorded through the agent's memory home, not restated in the corpus.

Concretely: the organ contributes the **policy** (consolidate corrections into standing dispositions), and the agent's running memory contributes the **particular dispositions** that policy has produced. One law, many lived instances.
