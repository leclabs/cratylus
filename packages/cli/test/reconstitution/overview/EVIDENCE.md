## Evaluation boundary

Recordings are authored controls with hand-scored rubric answers, explicitly not captured model runs. Offline proof establishes binding, schema, one-clause failures, no host reads and aggregation; it does not certify the live judge's semantic accuracy. The account rubric evaluates only the computed `account`, with fixture truth separately supplied to the judge. It also binds example 2's account sequence.

`EXECUTION_LIVE=1` opts into five independent live judgments. Every criterion needs four of five; never-assertions need all five. `EXECUTION_RECORDINGS` selects retained output. The lead should run these after the implementation is built, plus the normal package test command, type checking and affected judgment suites. The normal CLI configuration already discovers these files.
