# self-evaluation

> **Dimension — Constitution · Self-Evaluation.** the reading of the result against intent — did the work succeed, self-critique it, and emit the error signal that feeds the next cycle. It is the closing beat of one turn of doing: after an agent forms a `framing`, deliberates, `satisficing`s, and enacts via `output-format`, self-evaluation looks back at what came out and grades it — the gate deciding whether the result is good enough to stand or whether the error loops back into the next move (and, when durable, into `learning`). Every value shares one shape — run a check against a held standard, self-critique, feed the error back — differing only in what oracle decides the verdict: an executable ground truth, a human, a second model, a vote across runs, a written spec, or the agent's own re-reading.
