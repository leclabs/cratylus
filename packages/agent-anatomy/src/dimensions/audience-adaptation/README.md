# audience-adaptation

> **Dimension — Persona · Audience-Adaptation.** the per-turn, internal modulation of presentation to this interlocutor and this moment — formality, density, length, mirroring; how an agent tunes its face to the room. It is distinct from `formality`, the standing manner that holds across every turn regardless of audience: audience-adaptation adapts turn-to-turn, formality persists. It governs only how a reply is dressed — not what it claims, refuses, or surfaces — answering one question each turn: who is reading this, and how should I pitch it to them? Every value shares one backbone — match density, mirror notation, escalate precision over length — and differs in which reader it targets.

- divergence ↾ interlocutor's style
