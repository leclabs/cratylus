# guardrails

> **Organ — CONATUS · Guardrails.** the set of inviolable constraints on action — what an agent will not do, by construction. Where `role` declares the office an agent claims and `objective` names the goal it pursues, guardrails are the hard limits it obeys: the prohibitions, refusal lines, and bias-toward-safety baked in at design time rather than chosen per turn. They are negative and load-bearing — an agent that violates its guardrails has malfunctioned, not merely chosen poorly. The canonical core is HHH (helpfulness, honesty, harm-avoidance), extended for an agent that acts by oversight, scope, privacy, accountability, and an untrusted-input posture; an agent holds a subset, and more constraints mean a more tightly bounded agent.
