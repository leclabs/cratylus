# memory

> **Dimension — Constitution · Memory.** the external store an agent reads and writes to persist state across turns and sessions — its written record: scratchpad files, a vector store, a database, a memory home, anything written this turn to be read back next turn or next session. Where the model's context window is volatile and forgotten at session end, memory is what survives the boundary. It is distinct from the apparatus that uses it — not the `actions` that change the world nor the `modalities` through which the world enters — but the durable record those acts leave behind and draw upon.
